# slingshot-game

A p5.js + Matter.js slingshot game. Launch a rock using a slingshot mechanism to interact with blocks and stand structures. Features Block.js, Ground.js, SlingShot.js, Stand.js, and rock.png.

## Tech Stack

- **p5.js** — canvas-based creative coding library
- **p5.play.js** — sprite and collision support for p5.js
- **Matter.js** — 2D physics engine

## How to Run

Open `index.html` in a browser — no build step required. All libraries are vendored in the repo.
